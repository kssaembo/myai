# Visual Knowledge OS — 인터랙티브 관계·비교 지도

관계 지도를 읽기 전용 그림에서 사용자가 직접 탐색하는 작업 공간으로 확장했습니다. 별도 메뉴를
추가하지 않고 Dashboard의 `생각의 연결` 영역 안에서 관계 지도와 프로젝트 비교를 전환합니다.

## 관계 지도 조작

- 프로젝트 또는 관계 노드를 끌어서 원하는 위치에 배치할 수 있습니다.
- 빈 공간을 끌면 지도를 이동하고, 마우스 휠이나 `+`·`−`로 확대·축소합니다.
- 노드를 누르면 해당 노드의 1차 연결만 선명하게 남습니다.
- 같은 노드를 다시 누르거나 `전체 보기`를 누르면 모든 관계가 복원됩니다.
- 프로젝트를 선택하면 연결 개수와 프로젝트 상세 링크만 먼저 보여줍니다.
- 관계를 선택하면 짧은 요약을 먼저 보여주고 근거는 사용자가 펼칠 때만 표시합니다.

## 프로젝트 비교

- AI 관계에 포함된 프로젝트 중 2~4개를 선택합니다.
- 구조·기술·사용 경험·운영·교육·문제 해결·재사용 축으로 자동 정렬합니다.
- 각 칸은 Gemini가 저장한 프로젝트별 짧은 설명(`projectNotes`)을 우선 사용합니다.
- 공통 연결, 차이점, 비교 영역 수를 먼저 보여주고 상세 문장은 필요한 칸에서만 확인합니다.

## 분석 대상이 일부만 보이는 이유

`AI 허용 REF 23/23`은 문서 사용을 허용했다는 뜻입니다. 관계 분석 가능 프로젝트가 되려면 해당
REF의 active version Section이 프로젝트의 Evidence로 연결되어야 합니다. 한 번의 Gemini 분석은
무료 사용량과 응답 안정성을 위해 2~4개 프로젝트로 제한합니다. Dashboard의 `분석 대상`에서 다른
프로젝트 조합을 선택해 추가 분석할 수 있습니다. Gemini가 검증 가능한 공통 관계를 찾지 못한
프로젝트는 분석 대상이더라도 결과 지도에 나오지 않을 수 있습니다.

## 다크모드와 배포

- Header의 달/해 아이콘으로 전환하며 브라우저에 선택을 저장합니다.
- 새 SQL Migration은 없습니다.
- Edge Function 재배포도 필요 없습니다.
- 변경된 프런트엔드 파일을 GitHub에 올리고 Vercel을 재배포하면 됩니다.

다음 단계는 여러 비교 결과에서 반복되는 문제·해결책·재사용 구조를 묶는 `패턴 지도`입니다.
