# V2 단일 Jarvis Dashboard 배포

이번 단계는 데이터베이스 구조를 바꾸지 않고 첫 화면과 App Shell을 개인 AI 비서 중심으로 개편합니다.

## 변경 내용

- 데스크톱 고정 Sidebar를 접이식 보조 메뉴로 변경
- AI 대화, 현재 프로젝트, 추천 질문, 최근 흐름을 첫 화면에 통합
- 저장된 Relation과 최근 AI 답변 출처를 반영하는 생각 연결 지도 추가
- 질문을 입력하는 동안 제목·요약·Tag가 일치하는 지식이 우선 활성화
- Import와 설정은 상단 보조 버튼으로 유지

## 배포

1. 최신 프로젝트 파일을 기존 GitHub 저장소에 반영합니다.
2. `.env.local`, `node_modules`, `dist`는 업로드하지 않습니다.
3. Vercel 자동 배포가 `Ready`가 될 때까지 기다립니다.
4. 브라우저에서 `Ctrl+F5`로 새로고침합니다.

SQL Migration, Supabase Secret 변경, Edge Function 재배포는 필요하지 않습니다.

## 확인

- 첫 화면에 고정 Sidebar가 보이지 않는지 확인
- 좌측 상단 메뉴 버튼으로 기존 관리 기능에 접근되는지 확인
- 추천 질문을 누르면 질문 입력창에 문장이 들어가는지 확인
- 질문 입력 또는 AI 답변 후 하단 연결 지도의 활성 지식이 달라지는지 확인
- 모바일에서 대화, 현재 맥락, 연결 지도가 한 열로 표시되는지 확인
