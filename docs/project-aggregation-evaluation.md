# Step 10 Project Detail 수동 평가

완료 Gate는 **독점게임의 개발 지식을 한 화면에서 추적 가능**한지 확인하는 것입니다.

## 사전 조건

1. 독점게임 REF 문서를 업로드하고 파싱합니다.
2. REF 구조화에서 Project, Node, Evidence, Relation을 검토·저장합니다.
3. Projects 목록에서 생성된 독점게임 Project를 엽니다.

## 확인 항목

- [ ] 문서 탭에서 독점게임 REF와 현재 원본 Version을 열 수 있다.
- [ ] 문제–해결 탭에서 실제 오류와 최종 해결 방법이 쌍으로 표시된다.
- [ ] 결정 탭에서 변경 이유가 있는 설계 결정을 찾을 수 있다.
- [ ] 패턴 탭에서 재사용 Pattern과 금지 Pattern을 구분할 수 있다.
- [ ] 교훈 탭에서 실제 교실 운영 교훈을 찾을 수 있다.
- [ ] 각 구조화 Node에서 Evidence 발췌와 원문 Section으로 이동할 수 있다.
- [ ] 문서·문제·해결·결정·패턴·교훈 수와 Evidence 연결률이 표시된다.
- [ ] `unconfirmed` 또는 `conflicted` 항목 수가 검토 안내에 반영된다.

모든 항목을 원문과 대조해 통과하면 Step 10 Gate가 완료됩니다.
