# Knowledge Graph 수동 평가

1. Step 12 migration을 적용하고 앱을 다시 배포합니다.
2. Graph 메뉴에서 구조화·검토된 Project를 선택합니다.
3. 중심 Project와 최대 2-hop Node, 활성 Relation이 표시되는지 확인합니다.
4. 상태를 `제안` 또는 `모두`로 바꿔 제안 Relation 표시를 확인합니다.
5. Node 유형·Relation 유형·검색어를 적용해 화면이 즉시 필터링되는지 확인합니다.
6. Node를 선택해 요약·확인 상태·Evidence 개수를 확인하고 상세 화면으로 이동합니다.
7. Relation을 선택해 판단 근거·상태·Evidence 개수를 확인하고 Relation 관리로 이동합니다.
8. Relation이 100개를 넘으면 `Relation 100개 더 불러오기`로 점진 로딩을 확인합니다.

Graph에는 사용자가 저장·검토한 관계만 나타납니다. 원문을 구조화했지만 Relation을 저장하지 않았다면 Node만 보이거나 그래프가 비어 있을 수 있습니다.
