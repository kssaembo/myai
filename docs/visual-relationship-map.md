# Visual Knowledge OS Step 3 — 관계 지도

Step 2에서 생성한 AI 관계 인사이트를 별도 메뉴 없이 Dashboard의 `생각의 연결` 영역에
시각화합니다. 이번 단계는 데이터 구조나 Edge Function을 변경하지 않습니다.

## 표시 원칙

- 프로젝트는 지도 바깥쪽의 큰 노드로 표시합니다.
- 공통 구조, 차이점, 기술 연결, 재사용 요소, 반복 문제, 해결·개발 패턴, 교육 연결은
  중앙의 관계 노드로 표시합니다.
- 기존 V1 Relation은 옅은 점선으로 함께 표현합니다.
- AI 관계는 유형별 색상 연결선으로 프로젝트와 연결합니다.
- 관계 노드를 선택하기 전에는 긴 설명을 표시하지 않습니다.
- 선택 후에만 핵심 요약, 연결 프로젝트, 신뢰도, 근거 개수를 보여줍니다.
- 원문 근거는 `근거 확인`을 펼쳤을 때 최대 3개만 표시합니다.

## 호환성과 배포

- Visual Step 1·2가 적용된 기존 Supabase 데이터를 그대로 사용합니다.
- 새 SQL Migration과 Edge Function 배포는 필요하지 않습니다.
- 최신 프런트엔드 소스를 GitHub에 반영하고 Vercel을 재배포하면 됩니다.
- AI 관계가 아직 없으면 기존 질문 중심 생각 지도가 그대로 표시됩니다.

다음 단계에서는 여러 프로젝트를 사용자가 직접 고르고 공통점·차이점을 나란히 보는
`프로젝트 비교 지도`를 구현합니다.
