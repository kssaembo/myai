# 프로젝트 중심 지식지도

기본 지도는 프로젝트를 중심으로 해당 REF 원문과 기술·문제·패턴·교훈을 묶어 표시합니다. AI 관계 분석이 완료되면 프로젝트 사이의 공통점·차이점·재사용 요소를 별도의 관계 노드로 보여 줍니다.

## AI 관계 분석 준비 상태

Dashboard에서 다음 값을 바로 확인할 수 있습니다.

- 전체 프로젝트 수
- 실제 분석 가능한 프로젝트 수
- 전체 REF 수
- AI 사용이 허용된 REF 수

관계 분석에는 프로젝트마다 현재 Version의 근거가 있고 해당 REF의 AI 사용이 허용되어야 합니다. **REF AI 사용 허용**은 사용자가 직접 눌렀을 때만 전체 REF를 허용합니다.

## Gemini 사용량 확인

설정의 AI 연결 화면에서 앱 내부 일일 요청·입력 Token을 확인할 수 있습니다. 실제 Google Quota와 결제 여부는 같은 화면의 **Google 실제 사용량 확인**, **결제 계정·비용 확인** 링크에서 확인합니다. 앱 내부 한도는 과다 호출 방지 장치이며 Google 결제 한도를 대신하지 않습니다.

## 배포

이번 단계는 추가 SQL이나 Edge Function 배포가 없습니다. 최신 소스를 GitHub에 반영한 뒤 Vercel을 재배포합니다. 기존 REF 제목을 다시 정리하려면 Imports에서 **기존 REF 전체 정리**를 실행합니다.
