# V2 Step 5 — 개인화 브리핑·추천

## 구현 결과

- 대시보드 최초 진입 시 오늘 저장된 브리핑을 우선 표시합니다.
- 오늘 브리핑이 없고 지식이 존재할 때만 Gemini를 한 번 호출합니다.
- `새로 분석`은 사용자가 직접 눌렀을 때만 호출합니다.
- 브리핑은 하루 최대 2회 생성할 수 있고, 전체 AI 일일 요청 제한도 함께 적용됩니다.
- 추천은 최대 3개이며 각 추천에 실제 Knowledge Item 근거 링크가 표시됩니다.
- Gemini가 반환한 근거 ID는 서버가 실제 사용자 소유 지식인지 검증합니다.
- 생성 결과는 `ai_briefings`에 날짜별로 저장되어 새로고침 시 재사용됩니다.

## 배포 순서

1. `20260830000100_personal_briefings.sql`을 Supabase SQL Editor에서 전체 실행합니다.
2. `supabase/functions`를 포함한 최신 소스를 GitHub에 업로드합니다.
3. Supabase CLI에서 `ai-gateway`를 다시 배포합니다.
4. Vercel이 최신 프런트엔드를 배포했는지 확인합니다.
5. 대시보드에서 AI 브리핑과 근거 링크를 확인합니다.

새 Secret이나 이미지·사운드는 필요하지 않습니다.
