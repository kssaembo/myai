# REF 자동 구조화

REF 문서는 업로드 후 브라우저에서 본문을 추출하고, 형식이 충분히 확인되면 Project·기술·문제·해결·패턴·교훈으로 자동 연결됩니다. Gemini를 호출하지 않으므로 무료 AI 요청 한도를 사용하지 않으며 원문을 외부 AI로 전송하지 않습니다.

## 화면 원칙

구조화 결과는 다음 순서로 보여 줍니다.

1. 짧고 쉬운 개념명
2. 한 줄 설명
3. 사용자가 요청할 때만 원문 근거

Markdown 기호, 코드 조각, 긴 금지 문장은 기본 노드 제목으로 사용하지 않습니다. 예를 들어 `localStorage.clear()`는 `전체 브라우저 저장소 삭제`, `sort(() => Math.random())`는 `무작위 정렬 사용`으로 표시합니다.

## 새 문서

- `REF_`로 시작하는 파일 또는 REF ZIP을 가져오면 본문 추출과 구조화를 연속 실행합니다.
- 표준 REF 구성이 충분하면 자동 저장합니다.
- 확실하지 않은 문서는 임의로 저장하지 않고 검토 화면으로 보냅니다.

## 기존 문서

Imports 화면의 **기존 REF 전체 정리**를 한 번 실행합니다. 기존 Project·Relation·Evidence를 삭제하지 않고, 같은 근거에 연결된 노드를 재사용해 쉬운 제목과 요약으로 갱신합니다.

## 배포

1. `20260827000800_relation_evidence_merge.sql`이 아직 없다면 먼저 적용합니다.
2. `20260830000400_ref_auto_structuring.sql`을 Supabase SQL Editor에서 실행합니다.
3. 최신 소스를 GitHub에 반영하고 Vercel을 재배포합니다.
4. Imports에서 **기존 REF 전체 정리**를 실행합니다.

Edge Function 재배포나 새로운 Secret 등록은 필요하지 않습니다.
